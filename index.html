How To Play

🧪
Goal: Sort all colored liquids until every glass contains only one single color or is left completely empty.
👆
Tap to Select & Pour: Tap a glass to pick it up, then tap another glass to pour the top layer into it.
🎯
Matching Rule: You can only pour liquid onto the same color or into an empty glass, and only if the destination has space!
⌨️
Keyboard Controls: Use Arrow keys to navigate tubes, Enter / Space to select & pour, U for Undo, H for Hint, R for Restart.
